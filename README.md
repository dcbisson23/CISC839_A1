Not a lot to say I think?

Clone the repository to your working directory of choice, 
install any packages it asks you to install, and 
make sure to install Spider's database from https://github.com/taoyds/test-suite-sql-eval/blob/master/README.md after cloning that repository.

Also make sure you have adequate RAM in your hardware accelerator(s) (at least 15 GB) if you decide to run the generation code for yourself. 

All data generated and used in the report is available in data.
Use scripts/config.py to select file paths and whatnot.
